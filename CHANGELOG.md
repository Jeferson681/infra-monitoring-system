# Changelog

## v1.0.0 — First Stable Release

v1.0.0 — First Stable Release

Initial stable release of the Infra Monitoring System.
Collects host-level observability data and exposes it through a Prometheus-compatible endpoint, enabling consistent monitoring and operational visibility for infrastructure hosts.

Capabilities

- Modular package architecture designed for maintainability and extension.
- Host metrics collection (CPU, load averages, temperature, network throughput).
- Prometheus exporter with a standards-compliant /metrics endpoint.
- Containerized execution and CI validation pipeline.

Stability

This version marks an architecturally consolidated and stable release.
No breaking API changes are introduced in v1.0.0. Future breaking changes will target v2.0.0.

For the full change history and technical details, see the project commit log and release notes.
